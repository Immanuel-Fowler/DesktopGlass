2 · What the DesktopGlass mode switch does

Four places control one setting (island.hideDesktopIcons). The app watches it and applies three changes. Your previous Dock setting is remembered and restored.

flowchart LR
  a1(["Pill switch"]) & a2(["Wallpaper pop-up switch"]) & a3(["Settings → DesktopGlass mode"]) & a4(["Pill right-click menu"]) --> pref[("island.hideDesktopIcons")]
  pref --> apply["applyIslandPrefs()
runs on every settings change,
acts only on real changes"]
  apply --> f["FinderDesktopIcons
defaults write CreateDesktop
+ restart Finder"]
  apply --> d["DockAutoHide
save your setting → autohide on
+ restart Dock"]
  apply --> w["WallpaperController.refresh()"]
  w --> q{"Wallpaper set
and mode on?"}
  q -- no --> none["No windows:
normal macOS wallpaper"]
  q -- yes --> kind{"Kind"}
  kind -- image --> img["Image, aspect-fill"]
  kind -- video file --> vid["AVPlayer loop, muted
pauses when screens sleep"]
  kind -- YouTube link --> ytb["WebKit + YouTube player
hidden until playing · cropped 18%
skips end screen · resumes when uncovered"]
  ytb -. "not playing / offline" .-> fb["Fallback file shows underneath"]
